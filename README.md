# Business Website (React)

A responsive single-page business website built with React, with smooth scrolling between sections and Font Awesome icons.

![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=white) ![Font Awesome](https://img.shields.io/badge/Font%20Awesome-528DD7?style=for-the-badge&logo=fontawesome&logoColor=white)

## Features

- Hero, services, about and contact sections
- Smooth scrolling navigation (react-scroll)
- Responsive on mobile, tablet and desktop

## Tech stack

- React (Create React App)
- react-scroll, Font Awesome

## Getting started

```bash
npm install
npm start
```
